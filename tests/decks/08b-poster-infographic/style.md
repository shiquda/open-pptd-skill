# Style Brief — 中国新能源汽车 2025 年销量与充电网络单页数据看板

- **Goal and audience**: 面向汽车产业投资者、战略规划决策者与工业科技读者的年度产业高维全景数据看板；10秒内建立「规模跨越千万、车桩比达2.4:1、补能网络高密纵深覆盖」的宏观记忆点，随后支持对月度爬坡曲线、头部品牌格局与车桩比指标的深度研读。
- **Output scenario and canvas**: 1:1 方形大画幅看板 `[1080, 1080]`，适用于移动端高清长图分享、投研报告前置信息图折页及数字展厅高密度信息屏。
- **Core message in one sentence**: 2025年中国新能源汽车年销量突破1280万辆且渗透率逼近47%，全国充电基础设施跨越1350万台大关，车桩协同迈入网络化高质量发展新阶段。
- **Chosen visual concept/metaphor**: 「电网与车流的交响枢纽 (Electrified Grid Hub)」——以深邃工业暗场为空间基底，冷金高亮与极光绿阶梯构成电力能量与交付增长的视觉张力，规避通用科技蓝紫渐变。
- **Primary visual focus**: 顶部跨栏超大字号「1,287.4 万辆」主指标与「46.8%」渗透率几何色块，与左侧中部的年度交付及月度补能爬坡高分辨率折线散点复合图形成双视觉锚点。
- **Poster-level visual move (why this is not an ordinary content page)**:
  - 突破常规 PPT 均匀 3-4 张独立卡片平铺的僵化模式；
  - 采用「非对称工业数据场」布局：顶部通栏权威宏观断言 → 左翼高密度数据图表流（Matplotlib定制工业图谱） → 右翼原生几何矩阵与细分交付原生微型数据表 → 底部基础设施网络与车桩比全景指标带；
  - 使用大字重对比、网格辅助微标尺线、点阵标线，创造海报级的版面张力与出版物级严密感。
- **Visual DNA**:
  - 背景：深石墨碳黑 `#111317`（非纯黑），传递深邃沉稳工业感；
  - 辅色：能量金 `#F59E0B`（核心数据高光）、极光绿 `#10B981`（补能设施与正向增量）、冰川白 `#F9FAFB`（核心标题与大数）、金属银灰 `#9CA3AF`（辅助说明与尺度标注）、模块边框与刻度线 `#262B34`。
- **Primary visual medium and asset candidates compared**:
  - 方案A（通用卡片堆叠）：3个等宽矩形框分别放置销量、充电桩、车企排名。缺点：缺乏海报记忆点，退化为普通后台仪表盘。
  - 方案B（图文纯海报）：一张大车渲染图居中，文字环绕。缺点：真实产业数据承载力不足，缺乏可追溯的严密数据密度。
  - 方案C（工业级混合信息图，最终选定）：由本地 Matplotlib 生成高质量月度走势图与基础设施增长图，右侧嵌套原生 PPTD `<a:tbl>` 品牌交付排行宽表，底部搭配矢量绘制的网络拓扑枢纽带。兼具高阶出版物视觉质感与可编辑性。
- **Reading order and composition**:
  - 1. 顶部眉标与大标题结论断言；
  - 2. 主视线聚焦「1,287.4万辆」与「1,352.6万台」双千万量级核心大数；
  - 3. 视线下移至左侧月度交付与公桩增速复合图；
  - 4. 视线向右扫描「2025头部主流品牌交付量与充电生态微型表格」；
  - 5. 底部落地于「车桩比 2.4:1」网络承载能力分析带与权威官方源说明。
- **Color scheme and each color's role**:
  - `#111317`: 画布主背景色
  - `#1A1D24`: 数据模块背板底色
  - `#F59E0B`: 销量主强调金
  - `#10B981`: 补能设施强调绿
  - `#F9FAFB`: 标题与第一层级主文本
  - `#9CA3AF`: 标签、口径说明与次级数值
  - `#262B34`: 模块分割标尺线
- **Chinese and English fonts, size hierarchy**:
  - 主标题：思源黑体 / PingFang SC 32pt 加粗（行高1.2）
  - 核心大数字：42pt~48pt 极粗字体，紧凑字距
  - 模块标题：14pt~16pt 粗体
  - 表格与图表标签：9pt~10pt 等宽/清晰无衬线体
  - 脚注数据源：8pt 金属灰
- **Graphics/chart/connector language**:
  - 数据图表由 Matplotlib 生成高分辨率抗锯齿 PNG，深色无缝融合背景；
  - 表格采用无坚硬边框的原生 PPTD 表格，水平细发丝线分隔，右对齐数字；
  - 状态胶囊全圆角矩形，标明增长率与渗透率关键节点。
- **Information density, whitespace, and alignment**:
  - 维持左右与上下各 48pt 的边距，模块之间保留 16~24pt 呼吸缝隙；
  - 拒绝无意义装饰图标，每一个色块与线条均具备信息指示功能。
- **Tropes to avoid**:
  - 严禁出现等宽 2×2 或 3 列同构卡片；
  - 严禁出现蓝紫渐变科技风、玻璃拟态、发光霓虹外框；
  - 严禁编造任何虚假精度，所有数据均引自中汽协（CAAM）、乘联分会（CPCA）与中国充电联盟（EVCIPA）2025年公报。
